\begin{frame}{1. Problem and dataset}
  \begin{itemize}
    \item Data: Kaggle \emph{binaaz-sale-project}, 100,775 scraped rows, 51 columns, prices in AZN.
    \item \textbf{Task A}: regress the listing price.
    \item \textbf{Task B}: classify \emph{premium} vs.\ \emph{standard}; premium = price strictly above the \textbf{training median} (210,000 AZN).
    \item Models written from scratch in NumPy: decision tree, Pegasos SVM (+ random Fourier features).
    \item Compared with scikit-learn models with \textbf{matched} settings; test set scored \textbf{once}.
  \end{itemize}

\begin{frame}{2. Cleaning, features and the leakage we removed}
  \begin{itemize}
    \item One row per listing: keep the latest scrape (the same listing was in train \emph{and} test before).
    \item Plausibility filters (104 rows): price outside 5,000--20M AZN, area outside 8--$10^6$ m$^2$ (e.g.\ an 11 AZN flat).
    \item Areas in \emph{sot} converted to m$^2$; floor and building floors parsed; medians imputed; one-hot categories.
    \item \textbf{Leakage columns removed:} \texttt{unit\_price}, \texttt{total\_price} (derived from the target), plus IDs, URLs, free text, scrape time, view counts, currency.
    \item Split 70/15/15, seed 42, stratified by tier: 45,045 / 9,652 / 9,653. Scaler fitted on train only.
  \end{itemize}
\end{frame}

% 4 -------------------------------------------------------------------
\begin{frame}{3. Our decision tree}
  \begin{itemize}
    \item Impurity: Gini, entropy (Task B); MSE = variance (Task A).
    \item Split search: sort each feature once, scan midpoints with cumulative counts (or cumulative sums for MSE).
    \item Pick the split with the largest weighted impurity decrease; recurse.
    \item Hyperparameters: \texttt{max\_depth}, \texttt{min\_samples\_leaf} (also \texttt{min\_samples\_split}, \texttt{min\_impurity\_decrease}).
    \item Chosen on validation: Task A depth 8, leaf 10 (125 leaves); Task B entropy, unlimited depth (3,068 leaves).
  \end{itemize}
  \vspace{0.3em}
  \fig[0.6\linewidth]{fig_tree_depth_sweep.png}
\end{frame}

% 5 -------------------------------------------------------------------
\begin{frame}{4. Our Pegasos SVM}
  \begin{itemize}
    \item Hinge primal: $J=\frac{\lambda}{2}\|w\|^2+\frac1n\sum_i\max(0,1-y_i(w^\top x_i+b))$.
    \item Update, $\eta_t=1/(\lambda t)$, one random sample:
      $w\leftarrow(1-\eta_t\lambda)w+\eta_t y_i x_i\,[y_i f(x_i)<1]$, $b\leftarrow b+\eta_t y_i$.
    \item Non-linear extension: random Fourier features $\phi(x)=\sqrt{2/D}\cos(\omega^\top x+b)$, $\omega\sim\mathcal N(0,2\gamma I)$; then linear Pegasos.
    \item Joint $(\lambda,\gamma)$ grid on validation. Chosen: $D=1024$, $\gamma=0.01$, $\lambda=3\cdot10^{-5}$, 400,000 updates.
    \item Final model: $\|w\|=39.6$, margin width $2/\|w\|=0.0505$, 17,528 training points on or inside the margin; val F1 0.845.
  \end{itemize}
  \vspace{0.2em}
  \centering\fig[0.5\linewidth]{fig_svm_convergence.png}
\end{frame}

% 6 -------------------------------------------------------------------
\begin{frame}{5. Experimental setup}
  \begin{itemize}
    \item Metrics: RMSE, MAE, $R^2$ (and on log price); accuracy, precision, recall, F1, ROC-AUC, PR-AUC. All NumPy.
    \item Validation picks hyperparameters; \textbf{test scored once}; 5-fold CV (stratified for Task B) on train+validation.
    \item Seed 42 everywhere; \texttt{python -m src.run\_all} reproduces every number (deterministic).
    \item Baselines (matched): sklearn tree with the same settings; linear SVC with $C=1/(\lambda n)$; SGD hinge with $\alpha=\lambda$; RBFSampler+SGD for the RFF model.
    \item Fit times are per-fold wall-clock on one laptop: read them as ratios.
  \end{itemize}
\end{frame}

\begin{frame}{7. Where the models fail, and limitations}
  \small
  \begin{columns}[T]
    \begin{column}{0.5\textwidth}
      \begin{itemize}
        \item Top 1\% of prices (99 listings): bias $-1.48$M AZN, MAE 2.31M. Cheap listings are over-predicted ($+29{,}928$).
        \item Sparse districts (fewer than 200 train rows): median relative error 0.355 vs 0.177 elsewhere.
        \item SVM: precision 0.768 vs recall 0.922, it over-predicts premium. A tuned threshold may help (\emph{hypothesis, not tested}).
        \item Asking prices, not sale prices; about 700 possible re-posted ads kept; one seed, one split.
        \item Our NumPy tree is 5--30$\times$ slower than sklearn's (CV fit 4.5 s vs 1.0 s, 20.5 s vs 0.7 s).
      \end{itemize}
    \end{column}
    \begin{column}{0.48\textwidth}
      \figc{fig_error_price_quantile.png}
    \end{column}
  \end{columns}
\end{frame}
